강동자바라 차양 제작 견적기 v1.2
================================

[v1.2 품목명 정정]
차양 품목명을 ‘처마형’으로 정정했습니다.
선택 버튼, 단가표, 견적 목록, 복사 및 인쇄에 동일하게 적용됩니다.
단가, 평수 계산식, 바 규격 자동 선택 및 기존 데이터 형식은 변경하지 않았습니다.

[실행]
압축을 풀고 index.html을 크롬 또는 엣지에서 열어 주세요.
별도 설치나 로그인 없이 사용하는 단일 HTML 계산기입니다.
다른 파일이나 외부 서버를 불러오지 않으므로 인터넷 연결 없이 계산할 수 있습니다.
웹에 올릴 때에도 index.html 한 파일을 사용합니다.

[계산 순서]
차양 종류 → 렉산 두께 → 물받이 유무를 선택하고,
가로·세로(돌출, mm)와 수량을 입력하면 바로 계산합니다.
세로 길이에 따라 바 규격과 평당 단가가 자동으로 선택됩니다.
처음에는 실제 규격을 입력하도록 가로·세로가 비어 있습니다.
‘예시 넣기’를 누르면 평차양 50바, 2T, 물받이 없음,
가로 3000mm × 세로 1200mm, 수량 1개가 입력됩니다.

[v1.1 바 규격 자동 선택]
사용자 추가 기준의 ‘사이즈’를 세로(돌출) 길이로 해석해 반영했습니다.
세로가 정확히 500mm: 25바
세로가 800mm 이상: 50바
물받이 가산치(100/300mm)를 더하기 전, 입력한 세로 길이가 기준입니다.
가로 길이와 물받이 유무는 바 자동 선택 기준에 영향을 주지 않습니다.
500mm 미만 및 501~799mm는 기준이 없어 임의로 정하지 않습니다.
해당 사이즈에서는 바 규격 목록에서 직접 골라야 계산이 진행됩니다.
‘직접 선택’이 체크되어 있을 때에는 치수와 관계없이 선택한 바를 유지합니다.
60바 등 예외 규격은 ‘직접 선택’을 체크한 뒤 선택할 수 있습니다.
자동으로 돌아가려면 ‘직접 선택’을 해제하세요.
반원형 500mm는 자동 기준(25바)에 해당하는 단가 행이 없어 안내 후 계산을 막습니다.
제작 규격을 확인한 뒤 ‘직접 선택’에서 50바 또는 60바를 선택할 수 있습니다.
25바/3T 등 원본 단가가 비어 있는 조합은 기존처럼 단가 미등록으로 표시합니다.
바 규격이 바뀌면 직접 입력해 두었던 평당 단가는 해제되고 새 바 단가를 적용합니다.
바 규격 기준은 견적용 선택 규칙이며 구조 안전이나 제작 가능 여부의 검증이 아닙니다.

[기존 데이터]
기존 견적 목록의 바·단가·금액은 자동 변경하지 않습니다.
v1에서 저장한 JSON 파일도 불러올 수 있습니다.
이전 견적을 수정할 때 자동 기준과 다른 바는 ‘직접 선택’ 상태로 유지합니다.
상단 현재 입력값은 자동 모드에서 새 바 기준으로 다시 계산합니다.
파일명이나 저장 위치를 바꾸면 브라우저 자동 저장이 이어지지 않을 수 있으니,
기존 화면에서 ‘파일 저장’을 누른 뒤 새 계산기에서 ‘불러오기’를 사용하세요.

[확정 반영한 평수 공식]
물받이 있음: 가로 × (세로 + 300) ÷ 90,000
물받이 없음: 가로 × (세로 + 100) ÷ 90,000
입력 단위: mm. 가로와 세로는 정수로 입력합니다.
‘평’은 위 공식에 따른 제작 산출 단위입니다. 부동산 면적의 평이 아닙니다.

[금액 계산 및 초기 설정]
개당 제작금액 = 적용 평수 × 해당 조합의 평당 단가
현재 제작 계산금액 = 개당 제작금액을 1원 단위 반올림 × 수량
기본 설정에서는 평수를 올리지 않습니다.
‘평수 처리 설정’에서 ‘1평 단위 올림’을 선택할 수 있습니다.
화면에는 평수를 소수 6자리까지 표시하지만,
소수점 그대로 사용 모드에서는 표시값으로 잘라서 계산하지 않습니다.
금액은 원래 분수값으로 계산한 뒤 개당 원 단위 반올림합니다.
수량을 먼저 곱한 뒤 반올림하는 방식과는 차이가 날 수 있습니다.

[단가표]
보내주신 사진의 작성일자 2026.04.09 인쇄 단가를 옮겼습니다.
차양 4종(처마형·평차양·코너형·반원형)만 반영했습니다.
물받이가 있으면 세로 가산치뿐 아니라 평당 단가도 물받이 포함 열로 바뀝니다.
단가표의 빈칸은 미등록 상태이며, 0원 또는 임의 금액으로 계산하지 않습니다.
반원형의 바 규격은 직접 선택 모드에서 원본에 있는 50바·60바를 선택할 수 있습니다.
단가가 없는 조합은 ‘직접 입력’을 선택해 현재 견적의 단가를 넣을 수 있습니다.
차양 종류·바·두께·물받이 선택이 달라지면 직접 입력 모드를 해제하고
새 조합의 단가표 금액을 다시 적용합니다.

‘단가표 보기·수정’에서 평당 단가를 수정하고 저장할 수 있습니다.
원본으로 되돌리기를 누른 뒤 ‘단가 저장’을 눌러야 최종 반영됩니다.
단가 수정 내용은 해당 기기·브라우저에만 적용되며 다른 직원과 자동 공유되지 않습니다.
단가표는 품목 조합별 가격표일 뿐, 구조적 제작 가능 여부나 시공 안전을 판정하지 않습니다.

[반영하지 않은 비용]
사진의 손글씨 추가금, 배송비, 설치비 등은 임의로 반영하지 않았습니다.
원본에 단가의 부가세 포함·별도 여부가 명확히 표시되어 있지 않아
이 계산기에서는 부가세를 추가하거나 역산하지 않습니다.
사용 전 해당 단가의 부가세 기준 및 추가 비용을 확인해 주세요.

[여러 견적]
‘＋ 견적 추가’로 현재 계산값을 목록에 담습니다.
목록은 PC에서 한 줄에 3개 카드로 표시되며, 각 견적을 수정·삭제할 수 있습니다.
추가 당시의 단가·평수 처리 방식을 저장하므로
단가표나 현재 설정을 고쳐도 기존 목록의 금액은 자동으로 바뀌지 않습니다.
기존 견적을 바꾸려면 카드의 ‘수정’을 누르고 ‘수정 내용 저장’을 눌러 주세요.
견적 목록은 최대 300건입니다.

[복사·인쇄]
‘현재 견적 복사’는 현재 입력값만, ‘전체 복사’는 견적 목록 전체를 복사합니다.
고객명/현장명과 메모를 입력하면 함께 복사·인쇄합니다.
자동 복사가 제한되는 브라우저에서는 수동 복사 창을 제공합니다.
‘견적 인쇄’는 목록이 있으면 전체 목록을, 목록이 비어 있으면 현재 견적을 출력합니다.
수정 중인 입력은 목록에 저장하기 전까지 전체 목록 인쇄에 반영되지 않습니다.

[자동 저장·파일 저장]
입력 내용, 목록, 단가표는 같은 기기·같은 브라우저에 자동 저장을 시도합니다.
브라우저 설정이나 파일 실행 환경에 따라 자동 저장이 제한될 수 있습니다.
이 경우 상단에 안내가 표시됩니다.
브라우저 데이터 삭제, 파일 이동 또는 다른 기기 사용 시 저장 내용이 이어지지 않을 수 있습니다.
중요한 견적은 반드시 ‘파일 저장’으로 JSON 파일을 별도 보관하세요.
JSON 파일에는 현재 입력, 견적 목록, 고객명, 메모, 수정 단가표가 함께 저장됩니다.
‘불러오기’로 다시 열 수 있으며, 확인 후 현재 데이터 전체를 교체합니다.
여러 직원이 사용해도 실시간 동기화되지는 않습니다.

[검산 예시: 평차양 50바, 2T, 3000 × 1200mm, 1개]
물받이 없음:
3000 × (1200 + 100) ÷ 90000 = 43.333333…평
43.333333…평 × 8100원 = 351,000원

물받이 있음:
3000 × (1200 + 300) ÷ 90000 = 50평
50평 × 8600원 = 430,000원

위 예시는 평수 올림 없는 기본 설정이며, 부가세 추가 계산과 별도 비용을 포함하지 않습니다.
